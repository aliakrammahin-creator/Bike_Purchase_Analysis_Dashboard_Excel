# 🚴 Bike Purchase Analysis & Customer Insights Dashboard

## 📌 Project Overview

This project focuses on analyzing customer demographics and purchasing behavior to understand the factors influencing bike purchases.
Using Microsoft Excel, I cleaned and transformed the raw dataset, performed exploratory data analysis, and developed an interactive dashboard to present meaningful insights into customer purchasing patterns.
The dashboard allows users to explore customer segments and compare bike purchasing behavior using interactive slicers and visualizations.

## 🎯 Project Objectives

- Analyze customer demographics and purchasing behavior.
- Understand the relationship between customer characteristics and bike purchases.
- Explore purchasing patterns across different age groups, genders, and marital statuses.
- Examine the impact of income, occupation, education, and commute distance on bike purchases.
- Build an interactive dashboard to communicate findings effectively.

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Power Query (data preparation)
- PivotTables
- PivotCharts
- Slicers
- Excel formulas
- Data Cleaning & Transformation

## 📂 Dataset Description

The project uses a Bike Buyers dataset containing 1,000 customer records.
The dataset includes the following attributes:
- Customer ID
- Marital Status
- Gender
- Income
- Number of Children
- Education
- Occupation
- Home Ownership
- Number of Cars
- Commute Distance
- Region
- Age
- Age Brackets
- Purchased Bike (Yes/No)

## 🔄 Project Workflow

### 1. Data Cleaning & Preparation
- Inspected the raw dataset for inconsistencies and missing values.
- Removed unnecessary records and handled missing values.
- Standardized categorical values.
- Used **Power Query** to transform and prepare the dataset.
- Created a new **Age Brackets column using Conditional Column in Power Query** to segment customers into different age groups.
- Prepared the cleaned dataset for analysis.

### 2. Data Analysis
- Created PivotTables to summarize customer data.
- Analyzed bike purchases across different demographic groups.
- Compared average income between bike buyers and non-buyers.
- Explored purchasing patterns based on age, gender, marital status, and other customer attributes.

### 3. Dashboard Development
- Created interactive PivotCharts.
- Added slicers to filter customer segments.
- Designed a dashboard to make the analysis easier to understand.
- Connected interactive filters to relevant visualizations.

## 📊 Dashboard Features

The interactive dashboard provides:
- Customer demographic analysis.
- Bike purchase comparisons.
- Age group segmentation.
- Gender-based purchasing analysis.
- Income-based comparisons.
- Interactive filtering using slicers.
